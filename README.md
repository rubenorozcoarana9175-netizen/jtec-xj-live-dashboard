# JTEC XJ Custom Calibration Studio

A browser-based calibration-planning tool for custom Jeep Cherokee XJ modifications.

This project is for planning and comparison only. It does not flash a PCM and does not generate a stock HP Tuners `.hpt` file.

## Local preview

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit:

```text
http://localhost:8080
```

## GitHub Pages

After the repository has Pages enabled, the project will live at:

```text
https://rubenorozcoarana9175-netizen.github.io/jtec-xj-live-dashboard/
```

## Included features

- Editable spark table
- Editable fuel target table
- Idle target table
- Fan control table
- Vehicle and parts configuration
- Save/load custom project JSON
- Validation checks
- CSV log preview
